# 智慧医养大数据公共服务平台 · 接口文档（医生端 / 老人端）

> **文档版本**：v2.0
> **基础路径**：`http://localhost:8080/api`
> **认证方式**：除登录接口外，所有请求需在 Header 携带 `Authorization: Bearer {accessToken}`
> **参数规范**：Controller 与 Service 之间传递对象参数统一使用 DTO；Mapper 查询返回实体类，Service 层封装为 DTO 返回

---

## 通用说明

### 统一响应格式 Result

```java
public class Result<T> {
    private Integer code;    // 响应状态码：200-成功 500-失败
    private String message;  // 提示信息
    private T data;          // 响应数据
}
```

### 响应码定义（只有两种）

| code | 说明                                                                  |
| ---- | --------------------------------------------------------------------- |
| 200  | 成功                                                                  |
| 500  | 失败（参数错误/无权限/数据不存在/业务规则冲突等，具体原因见 message） |

**成功响应：**

```json
{ "code": 200, "message": "操作成功", "data": {} }
```

**失败响应：**

```json
{ "code": 500, "message": "该身份证号已存在档案记录", "data": null }
```

### 通用分页响应结构（data 内容）

```json
{ "total": 156, "pages": 16, "pageNum": 1, "pageSize": 10, "list": [] }
```

# 第一部分：医生端接口（userType = 2）

医生端面向家庭医生、专科医生、康复师、护理师，核心职责：**管理老人档案、执行评估、重点人群随访、设备查看、个人排班**。

## 1. 医生端登录

### 1.1 医生登录

| 项目     | 内容                           |
| -------- | ------------------------------ |
| 接口地址 | `/api/doctor/auth/login`       |
| 请求方式 | POST                           |
| 入参     | DoctorLoginDTO（@RequestBody） |
| 出参     | Result&lt;LoginRespDTO&gt;     |

**请求参数（DoctorLoginDTO）：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| phone | String | 是 | 手机号（医生账号） |
| password | String | 是 | 密码（加密传输） |
| captcha | String | 否 | 图形验证码 |
| captchaKey | String | 否 | 验证码key |
**响应示例：**

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiJ9...",
    "expiresIn": 7200,
    "userInfo": {
      "userId": 30001,
      "username": "13800138000",
      "realName": "王医生",
      "userType": 2,
      "avatar": "https://xxx/doctor.png",
      "roles": ["DOCTOR"],
      "doctorType": 1,
      "dept": "全科",
      "title": "主治医师"
    }
  }
}
```

**失败响应：** `{ "code": 500, "message": "账号或密码错误", "data": null }`
**失败响应（未审核）：** `{ "code": 500, "message": "账号待审核，请联系管理员", "data": null }`

### 1.2 医生退出登录

| 项目     | 内容                      |
| -------- | ------------------------- |
| 接口地址 | `/api/doctor/auth/logout` |
| 请求方式 | POST                      |
| 出参     | Result&lt;Void&gt;        |

### 1.3 医生注册（入驻申请）

| 项目     | 内容                                         |
| -------- | -------------------------------------------- |
| 接口地址 | `/api/doctor/auth/register`                  |
| 请求方式 | POST                                         |
| 入参     | DoctorRegisterDTO（@RequestBody @Validated） |
| 出参     | Result&lt;Void&gt;（提交后进入待审核状态）   |

**请求参数（DoctorRegisterDTO）：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 是 | 姓名 |
| phone | String | 是 | 手机号 |
| password | String | 是 | 密码 |
| doctorType | Integer | 是 | 1-家庭医生 2-专科医生 3-康复师 4-护理师 |
| title | String | 否 | 职称 |
| dept | String | 否 | 科室 |
| orgId | Long | 否 | 所属机构ID |
| qualifications | List&lt;DoctorQualificationDTO&gt; | 是 | 资质证书列表 `[{certType,certNo,certImgUrl,validDate}]` |
